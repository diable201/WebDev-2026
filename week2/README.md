# Week 2 — Web Development Roadmap · HTML & CSS

## Topics Covered

- **Web development roadmap** — overview of the full-stack learning path for 2026
- **HTML Elements and Attributes** — semantic tags (`header`, `main`, `section`, `footer`, `nav`), attributes, accessibility (`aria-*`, `alt`)
- **HTML Forms & Inputs** — `input` types, `select`, `textarea`, `fieldset`/`legend`, native browser validation (`required`, `type="email"`, `minlength`)
- **Introduction to CSS** — ways to add CSS (inline / embedded / external), the cascade, specificity, the box model
- **HTML5 / CSS3 features** — CSS custom properties (`--var`), Flexbox, Grid, transitions, media queries, `prefers-reduced-motion`

## Laboratory Work #2

Built a **Mini Profile** single-page site ([`index.html`](index.html) + [`styles.css`](styles.css)) demonstrating:

- Semantic HTML structure with `<header>`, `<main>`, `<footer>`, `<section>`
- Navigation links that jump to page anchors (`href="#id"`)
- A contact form with multiple input types, radio buttons, a checkbox, and native validation
- CSS custom properties for a consistent dark-mode colour palette
- Flexbox header and CSS Grid two-column page layout
- Responsive breakpoint that collapses to a single column on narrow screens (`max-width: 820px`)
- Hover transitions and `prefers-reduced-motion` accessibility support
