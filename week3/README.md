# Week 3 — JavaScript

## Topics Covered

- **JavaScript Basics** — syntax, data types, operators, control flow
- **JavaScript Standards (ES6+)** — `let` / `const`, arrow functions, template literals, destructuring, spread/rest, modules
- **Data Types and Variable Scoping** — `var` (function-scoped / hoisted) vs. `let`/`const` (block-scoped); `const` with objects
- **Functional Programming Concepts** — pure functions, `map`, `filter`, `reduce`, method chaining, generator-based lazy pipelines
- **Working with JSON** — `JSON.stringify()`, `JSON.parse()`, pretty-printing with `null, 2`
- **DOM Manipulation** — `querySelector`, `querySelectorAll`, `textContent`, `classList`, inline styles, creating/appending/removing elements
- **Event Handling** — `addEventListener`, click, input, keydown events, `setTimeout`, `setInterval`, `getBoundingClientRect`
- **HTML Element Manipulation** — dynamic list rendering, toggling CSS classes, clearing inputs
