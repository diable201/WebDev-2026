# Week 1 — Introduction to Web Development

## Topics Covered

- **What is a website?** — static vs. dynamic pages, how browsers render content
- **How does the Web work?** — DNS, HTTP/HTTPS request-response cycle, servers
- **Client-side vs. Server-side technologies** — what runs in the browser vs. on the server
- **Frameworks & Libraries** — difference between a framework and a library; popular choices
- **Back-End framework comparison** — Express, Django, Spring, Laravel and when to use each
- **Basic techniques for scaling** — horizontal vs. vertical scaling, load balancers, caching
- **What is an API?** — REST, request/response structure, JSON data exchange

## Laboratory Work #1

Introductory lab: setting up the development environment, installing Node.js and a code editor, creating and opening a first HTML file in the browser.
